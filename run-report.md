## Agent-side verification

Chromium is architecturally blocked on this machine for the headless `llmagent` account: renderer children die with `Mach rendezvous failed`/`bootstrap_unknown_service` (no `gui/504` launchd domain), and even `--single-process --headless=new` traps in macOS 14+ WindowManagement (`_xpc_api_misuse` → `xpc_connection_set_target_uid` → `-[WMClientWindowManager _createXPCConnection]`; same as electron/electron#45440 and matplotlib#26292 — any AppKit app run by a non-GUI-logged-in user crashes). The working browser-automation path is **safaridriver**, confirmed by `scripts/verify-safari.mjs`.
